# HowToFind Bot

**Telegram-бот — каталог бесплатных ресурсов для поиска информации из открытых источников.**
5000+ ссылок: сайты, приложения, программы, Telegram-боты и пошаговые инструкции.

---

## О проекте

HowToFind Bot помогает находить публичные ресурсы для поиска информации из открытых источников (OSINT) — по номеру телефона, аккаунту, email, ФИО, адресу, транспорту, документам, кошелькам, Wi-Fi и многому другому.

Контент организован по категориям и странам, с навигацией и полнотекстовым поиском по всем базам сразу.

| Команда | Описание |
|---------|----------|
| `/adm`  | Открыть админ-панель (рассылка / переименование / статистика) |
| `/stat` | Показать полную статистику бота |

## Установка

Открой `bot.py` и заполни:

- **`TOKEN`** — токен бота от [@BotFather](https://t.me/BotFather)
- **`CHANNELS`** — 2 канала, на которые должны быть подписаны пользователи (бот должен быть там админом)
- **`ADMIN_IDS`** — твой Telegram ID, узнать можно у [@userinfobot](https://t.me/userinfobot)
- **`DB_LINK`** — ссылка на закрытый канал, которая выдаётся после оплаты звёздами
- **`STARS_PRICE`** — цена в звёздах Telegram

> 💡 В архиве уже есть готовая папка `venv310` со всеми зависимостями — устанавливать ничего не нужно. Просто распакуй архив и запусти `start.bat`.
