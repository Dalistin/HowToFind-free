Для файла формата изображение

1. https://www.metadata2go.com/view-metadata — покажет EXIF и метаданные картинки
2. https://stolencamerafinder.com/ — определит EXIF и по этим данным найдет какие еще фото были сделаны этим устройством
3. https://29a.ch/photo-forensics/#level-sweep — фото-форензика, анализ изображения на изменения
4. https://stylesuxx.github.io/steganography/ — декодирует скрытое сообщение в изображении
5. https://github.com/beurtschipper/Depix  — депикселизирует текст на картинке, помогает узнать слова и буквы которые были замазаны с помощью пикселизации (локальный скрипт)
6. https://focusmagic.com/  — восстановит детали и резкость размытых фотографий
7. https://forensicdots.de/ — ищет на скане документа желтые точки являющиеся уникальным идентификатором принтера
8. https://www.diffchecker.com/image-diff/ — помогает найти различия двух картинок
9. https://compress-or-die.com/analyze-process — показывает ICC_Profile, в нем можно по скриншоту на Mac узнать дату последнего обновления системы, есть EXIF и таблица квантования яркости
10. https://exiftool.org/  — программа для чтения, записи и редактирования метаинформации, определит производителя многих цифровых камер
11. https://github.com/ianare/exif-py  — выгружает метаданные из большого объёма изображений (Python-библиотека)

2. https://www.google.com/imghp — открывать на ПК
3. https://www.bing.com/visualsearch — визуальный поиск по изображению
4. http://tineye.com/ — точный поиск по хэшу изображения
5. https://agent.earthkit.app/  — найдет место съемки, дает очень хорошие результаты
6. https://www.numlookup.com/reverse-image-search — поиск по картинке с AI
7. https://searchbyimage.app/  — находит товары в многих интернет-магазинах
8. http://thieve.co/tools/image-search — находит товары в Aliexpress
9. https://www.aliseeks.com/search/ — находит товары в Aliexpress и eBay
10. https://image.baidu.com/ — китайский поиск по картинке
11. https://image.so.com/ — китайский поиск по картинке
12. https://saucenao.com/ — поиск аниме/арт по изображению
13. https://depositphotos.com/search/by-images.html — стоковый поиск по фото
14. https://geoguessr.ai/tools/reverse-image-search-location — найдет примерное место съемки фото AI-геолокация
15. https://www.placespotter.com/  — найдет примерное место съемки фото AI-геолокация

Инструменты

1. https://magiceraser.io/ — качественно удалит выделенную область на фото, необходимо для подготовки фото к поиску по картинке
2. https://waifu2x.booru.pics/ — улучшает качество картинки (апскейл и шумодав)
3. https://app.remini.ai/ — сделает картинку четче (AI-улучшение)
4. https://upscayl.org/  — улучшает качество картинки (AI-апскейлер, десктоп)
