Поиск через URL

1. https://psbdmp.ws/api/search/domain/example.com — упоминания в утечках на Pastebin, замените example.com, сайт выдаст id страниц, подставь этот ID в ссылку pastebin.com/ID


Архив

1. https://timetravel.mementoweb.org/ — найдет сохраненные копии сайта среди 30 ресурсов для архивации
2. https://web.archive.org/ — показывает сохранённые копии страниц, исходный код, все директории сайта, статистику и много другого
3. https://cachedview.com/ — найдет копию сайта из кэша Google
4. https://oldweb.today/ — найдет исторические версии сайтов, можно выбрать вид браузера и дату
5. https://arquivo.pt/ — есть расширенный поиск по сайту
6. https://archive.md/ — помимо HTML версии архивирует скриншот сайта
7. https://trove.nla.gov.au/ — найдет копию страницы, откройте расширенный поиск и укажите домен, можно искать в архиве страниц по ключевому слову
